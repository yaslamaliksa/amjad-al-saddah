# منيو أمجاد السدة | فرع الشوقية

منيو عربي تفاعلي بتصميم القائمة الأصلية. يتيح اختيار الأحجام والإضافات، وحساب الإجمالي، وتجهيز رسالة الطلب لإرسالها إلى واتساب الفرع.

## النشر على GitHub Pages

1. فك ضغط الحزمة وارفع محتوياتها إلى جذر المستودع. ضع `index.html` وملفات JavaScript وCSS ومجلد `assets` في مستواها الحالي. يمكنك استخدام GitHub Desktop أو Git لرفع الملفات دفعة واحدة.
2. افتح إعدادات المستودع، ثم **Settings → Pages**. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**. إذا كان للفرع اسم مختلف فاختر اسم الفرع الذي رفعت الملفات إليه.
3. بعد اكتمال النشر، يظهر عنوان الموقع في **Settings → Pages**. الموقع ثابت ويعمل مباشرة من الملفات المرفوعة.

## تعديل المنيو

- `menu.js` يحتوي على أسماء الأصناف والأسعار والأحجام والإضافات.
- `assets/original-menu/` يحتوي على الغلاف وصور الصفحات. إذا عدّلت سعرًا مطبوعًا في صورة، حدّث الصورة وبيانات الصنف معًا.
- `posters.js` يحدد مواضع البطاقات القابلة للضغط على صور القائمة.
